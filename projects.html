Rock Paper Scissors with Java

Overview

A console-based Rock Paper Scissors game written in Java. Users enter their choice (Rock, Paper, or Scissors), and the program displays the computer's randomized choice and announces the winner.

Key Concepts

  • "Random" class and "Scanner" class
  • One dimensional arrays
  • "While" loops
  • Nested "if-else" conditionals

Outcomes

Implemented nested "if-else" conditionals inside a "while" loop for game logic.
Used the `Random` class to select an element from an array randomly.
Utilized the `Scanner` class to handle user input.
